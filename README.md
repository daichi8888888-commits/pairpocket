# ♥ PairPocket (ペアポケット)

ふたり暮らし・カップル向けの共有家計簿 ＆ 暮らし管理Webアプリです。  
日々の割り勘・立替精算だけでなく、AIによるレシート仕分け・音声スマート入力・献立提案・ミニゲーム・予定管理まで、ふたりの暮らしを便利に楽しくする機能をひとつにまとめています。

---

## ✨ 主な機能

### 1. 💰 かんたん支出入力 ＆ 割り勘計算
- **電卓機能つき入力** : `1200+350` のような計算式入力や、`+100` / `+500` / `+1,000` クイックボタン、`÷ 2人で割り勘` ボタンで素早く入力。
- **📷 AIレシート読込** : レシートを撮影すると Gemini AI が品目と金額を自動抽出し、「自分(0%) / 折半(50%) / 相手(100%)」をワンタップで仕分け。
- **🪄 AI文章・音声スマート入力** : 「🎙️ マイクで話す」で録音すると Gemini AI が文字起こしし、複数の支払いを自動解析して一括登録（文章入力にも対応）。
- **🔄 定額・サブスク自動追加** : 毎月の指定日（1〜31日・月末対応）の0時以降に家賃やサブスクを自動追加。

### 2. 🤝 リアルタイム同期 ＆ 精算管理
- **🔄 ワンタップ更新 ＆ 即時同期** : 画面右上の「🔄 更新」ボタンでの強制同期に加え、Supabase Realtime とバックグラウンド同期でパートナーの追加・編集・削除・名前変更を即座に反映。
- **差額の自動集計 ＆ 一部/全額精算** : 現在の貸し借り差額をリアルタイム表示し、全額または指定金額での精算・取り消しが可能。
- **タイムライン履歴 ＆ 🧾🎙️🪄内訳・入力データ表示** : 支出と精算完了ラインを時系列で表示。レシート登録分（`🧾`）は品目ごとの内訳・負担割合、音声・AI文章登録分（`🎙️`/`🪄`）は「聞き取った元の言葉（入力データ）・支払総額・割り勘計算の内訳」を金額タップで確認可能。
- **🤖 AI家計簿アナリスト** : 履歴データをもとに、AIが月ごとの傾向・褒めポイント・節約＆お出かけアイディアをレポート。

### 3. 🍳 AI ＆ お楽しみ・暮らし管理機能（サイドメニュー `☰`）
- **🍳 今日のAI献立提案** : 冷蔵庫の食材テキストや写真と「今日の気分（時短・ガッツリ・ヘルシー等）」から、AIシェフが3品のレシピを提案。
- **🎟️ ご褒美・おねだりチケット** : 「カフェ奢り券」「運転交代パス券」などのチケットを発行・使用管理。
- **🎮 待ち時間ミニゲーム** : ふたりで遊べる「反射神経バトル」「爆弾ゲーム」「AI 4択クイズ（2人同時回答＆採点対応）」を搭載。
- **📅 ふたりの予定管理** : カレンダー複数日選択・期間/繰り返し登録に対応し、スマホのカレンダー（`.ics`）へ一括書き出し可能。
- **💧 水道・光熱費グラフ** : 水道代・光熱費の月別推移グラフと月平均額を可視化。

## 🛠 技術スタック・環境変数

- **フロントエンド** : Vite + TypeScript + Vanilla CSS (PWA対応)
- **バックエンド / DB** : Supabase (Auth, Database, RPC, Realtime)
- **AI** : Google Gemini API (`gemini-3.6-flash`)

### 環境変数（Vercel / `.env`）
- `VITE_SUPABASE_URL` : Supabase プロジェクトURL
- `VITE_SUPABASE_ANON_KEY` : Supabase Anon Key
- `VITE_GEMINI_API_KEY` : Google Gemini APIキー

### v21.3.0（2026-11-15）- 音声・AI入力データの履歴タップ詳細表示対応版
- 音声入力（`🎙️`）やAI文章入力（`🪄`）で追加した支出も、履歴タイムラインの金額ボタン（`🎙️ ¥〇〇 ▾` / `🪄 ¥〇〇 ▾`）をタップすると **「聞き取った元の音声テキスト（入力データ）」「元の支払総額」「計算方法（2人で割り勘50%など）」** が見られる詳細モーダルを追加。

### v21.2.0（2026-11-15）- ワンタップ即録音＆全自動AI登録対応版
- 入力画面のトップに **「🎙️ 音声で追加」ボタン** を直接配置し、モーダルを開かずに **1タップした瞬間に録音が開始** するように改善。
- 話し終わってもう一度タップすると、Gemini AI が音声から直接「品名・請求額・支払者・カテゴリー」を抽出し、**確認ボタンを押す手間なく全自動で家計簿へ登録完了** するダイレクト音声登録モードを搭載。

### v21.1.0（2026-11-15）- AI音声入力 録音＆Gemini文字起こし対応版
- **音声入力が使えない不具合を修正**。ブラウザの音声認識（Web Speech API）は iPhone のホーム画面アプリ（PWA）や一部ブラウザで動かないため、**マイク録音 → Gemini で文字起こし** する方式に変更。
- 文字起こし後は自動で「AIで解析する」まで実行されるように改善（録音は最大60秒、録音中は秒数を表示）。
- マイク権限が拒否されている場合など、原因ごとに分かりやすい案内を表示するように改善。
- 録音中・モーダル表示中はバックグラウンド同期による画面の再描画を保留し、操作が途切れないように修正。

### v21.0.0（2026-11-15）- ワンタップ更新ボタン＆即時リアルタイム同期対応版
